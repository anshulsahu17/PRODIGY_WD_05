# Weather App — Prodigy InfoTech Task 05

A responsive weather application built with HTML, CSS, and vanilla JavaScript. It lets users search for a city or use their current location to view current weather conditions and a five-day forecast.

## Features

- Search for a city by name
- Use browser geolocation to get local weather (permission required)
- Current temperature and weather description
- Celsius and Fahrenheit display toggle
- Today's high and low temperatures
- Humidity, wind speed and direction, feels-like temperature, and UV index
- Five-day forecast with weather icons and high/low temperatures
- Responsive design for desktop and mobile
- Loading and error messages

## APIs

This project uses the free Open-Meteo APIs and does not require an API key:

- Geocoding: `https://geocoding-api.open-meteo.com/v1/search`
- Forecast: `https://api.open-meteo.com/v1/forecast`

Weather data is provided by Open-Meteo. Network access is required for search and weather results.

## Run locally

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser. For geolocation, use localhost or a secure HTTPS origin.

No build tools or JavaScript dependencies are required.
